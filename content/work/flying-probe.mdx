## The problem

The flying probe tester dashboard is something real operators look at during
a live shift. It was built in WPF, and moving it to a modern web stack meant
touching a tool people depend on continuously — with none of the slack a
green-field rewrite would have.

## What I built

A migration of the dashboard from WPF to React and Redux, backed by the
existing C#/.NET services. Same operator-facing functionality, new stack
underneath it.
